# HitResult

`HitResult` provides the complete chronological output stream in `records`
(what `len()`, iteration, indexing, `dataframe()`, and `plot()` all use), a
stable scheduled-sample table in `samples`, and exact physical event roots
in `events`. `trajectory` is a deprecated alias for `records`. See
[Trajectory Data](../concepts/trajectory_data.md) for the output-view
contract and examples.
